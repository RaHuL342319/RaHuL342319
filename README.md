## 🚀 What I've Built

> Client projects are proprietary, so source code isn't public. Here's what I worked on and the impact.

### 🏢 Internal Branch Operations Web Portal &nbsp;`2025 – Present`
**Public Sector Insurance Provider** &nbsp;|&nbsp; `React.js` `TypeScript` `Redux Toolkit` `CSS Modules` `Jest`

- Architected and built an internal portal from scratch, replacing legacy insurance workflows for staff across branches nationwide
- Built the **design system from scratch** in TypeScript and CSS Modules: reusable components, tokens and layout patterns
- Implemented **role and feature-based journey mapping** that renders UI flows from feature IDs and user roles
- Cut page load time by **~20%** on high-traffic sections using lazy loading, code splitting and memoization, validated with Lighthouse and Chrome DevTools

### 📱 Customer Mobile Application &nbsp;`2023 – 2025`
**Public Sector Insurance Provider** &nbsp;|&nbsp; `React Native` `TypeScript` `Redux` `CSS Modules` `Jest`

- Built an iOS and Android app for policyholders to view policies, track claims and manage insurance accounts
- Implemented a **Micro Frontend (MFE) architecture** of independently deployable modules, enabling parallel team development
- Integrated a **payment gateway end-to-end**: payment initiation, transaction state, success/failure flows and receipt generation
- Optimized for low-end devices with lazy loading, fewer re-renders and efficient Redux state design

### 🏦 Banking Web Application &nbsp;`2021 – 2023`
**Leading Private Sector Bank** &nbsp;|&nbsp; `React.js` `JavaScript` `Redux` `CSS Modules` `Jest` `React Testing Library`

- Started in production support, resolving critical UI bugs, API failures and state defects under live SLA conditions
- Moved on to owning complete features end-to-end: transaction history, account dashboards and reporting modules
- Delivered with modular architecture and **85%+ test coverage**
